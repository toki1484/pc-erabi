## フェーズ1 — まず30分、費用0円で「動くサイトを公開する」

ここが全ての起点。順番に意味があるので、上から埋めること。

### [ ] 1. 楽天ウェブサービスのアプリID発行

- https://webservice.rakuten.co.jp/ でアプリIDを発行
- 取得した ID を `.env` に記載する
- **完了条件**: `npm run prices` の出力が「実データ」になる
- 用途: **価格データの取得のみ**。報酬上限があるため本体の販売導線には使わない

### [ ] 2. GitHubリポジトリの作成と Secrets 登録

- リポジトリは作成済み（本リポジトリ）
- `.env` に入れた値を GitHub の Settings → Secrets and variables → Actions に登録する
- **完了条件**: Actions のワークフローを手動実行して成功する
- **注意**: `.env` は絶対にコミットしない（`.gitignore` に入っていることを確認）

### [ ] 3. Cloudflare Pages に接続

- Cloudflare アカウントを作成（無料）
- 本リポジトリを Pages に接続してビルド設定を行う
- **完了条件**: 公開URLが発行される

> **この1〜3が終われば、実データの動くサイトが公開される。費用0円、所要30分。**

## フェーズ2 — 収益化の接続

### [ ] 4. A8.net 登録 → パソコン工房に提携申請

- https://www.a8.net/ に登録（**審査なしで即通る**。サイト未所持でも登録可）
- パソコン工房のプログラムに提携申請
- **完了条件**: 提携が承認される
- 所要: 15分

### [ ] 5. ドメインの取得

- 年1,000〜1,500円
- Cloudflare Registrar またはお名前.com
- Cloudflare Pages に独自ドメインとして設定する

### [ ] 6. バリューコマース審査申請 ← **収益化のクリティカルパス**

- **前提: 記事が5〜10本公開されていること。** サイト審査があるため、記事がないと通らない
- マウスコンピューターはバリューコマースの独占案件であり、
  **報酬上限がないのはここだけ**。ここが通るまで収益は事実上頭打ちになる
- 所要: 15分（審査待ちは別）
- 落選した場合: 理由を確認して再申請。3回落ちたら A8.net 中心に組み替える

# サイトB（レンタルサーバー領域）の調査と判断

調査日: 2026年9月13日 / 担当: market-analyst / 判断: ワッツ

## 判断: 保留する

**「勝てないから」ではなく、「順序が違うから」保留する。**

| 分かっていること | 分かっていないこと |
|---|---|
| 上位表示できれば実質EPCは現行の4.7倍 | **上位表示できる確率** |
| 確認を効率化する仕組みは作った | **確認が実際に何分かかるか** |

週に何本公開できるかが決まらない限り、2サイト体制が成立するかも決まらない。

```
確認1本30分 → 週2本 → 13週で26本 → 2サイトなら各13本（閾値ぎりぎり）
確認1本10分 → 週6本 → 13週で78本 → 2サイトなら各39本（両方成立）
```

**測っていない数字の上に体制を建てない。** 記事2本目の確認で実測してから決める。

## この調査の確度

**一次情報はゼロ。** 全ドメインがプロキシに遮断され、運営者情報ページを1件も開けていない。
検索は米国地域の結果を返すため、**日本のSERPを直接観察したものではない。**

調査担当自身が「意思決定に足る精度に達していません」と報告している。その判断は妥当である。

## それでも重い材料が3つ出た

### 1. 紹介したい相手が、最大の競合である

レンタルサーバーの比較・おすすめ記事を、**サーバー会社自身が自社ドメインで運営している。**

| 運営 | ドメイン数 | 例 |
|---|---|---|
| GMO系 | **7** | ロリポップメディア、ワプ活(ConoHa)、WEB学園(お名前.com)、バリューノート、起業の窓口 |
| その他 | 6 | さくらのホームページ教室、エックスサーバーのブログ、ラッコサーバープラス、Kinstaブログ、CPI |

**他ジャンルでは珍しい構造である。** ゲーミングPCでマウス自身が比較記事を書いている状況に相当する。
紹介対象が同時に最大の競合であり、自然な露出・引用・被リンクが期待しにくい。

### 2. 「実測」という差別化軸は既に埋まっている

| サイト | 内容 |
|---|---|
| `hostingstock.net` | **40社以上を自作ツールで長期連続測定**。測定方法の解説・変更告知まで記事化。定点観測型 |
| マイベスト | 17サービスを5観点で自社検証。月間3,000万ユーザー |
| pico.inc / serverfield.org ほか | 10〜18社の表示速度実測比較 |

**「開発者が実測する」は唯一性を持たない。** hostingstock は思いつきの実測ではなく、
計測インフラを構築・運用し続けている性格のサイトである（運営者が企業か個人かは未確認）。

### 3. 「最競合ジャンル」という前提に裏付けが無かった

ワッツが前提として語っていた「レンタルサーバーは国内で最も競合が激しい領域のひとつ」は、
**裏づける記述が見つからなかった。** レッドオーシャンと名指しされていたのは
転職・美容・金融・健康食品であり、レンタルサーバーは含まれていない。

**二次情報すら確認せずに語っていた。** 記録として残す。

## 方向性自体は否定されていない

複数の二次情報が一致して、2026年3月コアアップデートについてこう報じている
（Google公式ではなく、SEOベンダー/メディアの観測）。

- 追跡対象アフィリエイトサイトの**71%が順位を下げた**
- 打撃を受けた類型: **テンプレート化された比較ページ、一次検証を欠いたレビュー**
- 伸びた類型: **独自データ、一次ケーススタディ、実体験に裏づけられたコンテンツ**
- 「E-E-A-T の Experience はもはや補助的シグナルではなく、しばしば決定要因」

**うちのやり方（検証済みデータ・一次情報・限界の明示）は、この方向と一致している。**
問題はやり方ではなく、**どの領域でそれをやるか**である。

## 拾っておく論点

### Kinsta には継続報酬がある

「成約のサーバープランに対して毎月5%の継続報酬」とする二次情報がある。
**海外事業者だが日本語ページを持ち、日本人読者に日本語で紹介できる。**

前回「継続報酬は日本に存在しない」と結論したが、正確には
**「国内ASPの主要案件には存在しない」**であり、海外事業者の直契約には存在しうる。

ただし参加条件・税務・支払いは**すべて未確認**。
[overseas-research.md](overseas-research.md) で海外を見送った理由（税務・英語集客）のうち、
**英語集客の問題は当てはまらない**。再検討の余地はある。**いま追わない。**

### ConoHa WING は もしもアフィリエイト経由の条件も見る価値がある

A8での一次データは取れているが、もしも経由は即時提携で振込手数料も無料とする二次情報がある。
また「ConoHa WING は他社に比べて成果条件が多く設定されている」という記述もあり、
**A8管理画面で成果条件の詳細を確認する価値がある**（確定率93.85%の内訳）。

## 判断を覆す条件

1. **確認時間の実測で、週6本以上が可能だと分かった**場合 → 2サイト体制が成立する
2. サイトAで3ヶ月走り、**ジャンルが原因で機能しないと特定できた**場合 → 移行先として再浮上
3. 日本のSERPを実際に目視し、**個人サイトが上位に残っていることが確認できた**場合

3 は事業主が手作業で1時間かければ一次情報にできる
（「レンタルサーバー おすすめ」「比較」「Node.js」の上位10件の運営者を数える）。
**ただし、その1時間はいまサイトAの実測データに使うほうが価値が高い。**

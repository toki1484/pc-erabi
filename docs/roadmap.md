# 事業ロードマップ

pc-erabi を「趣味のサイト」ではなく「収益を出す事業」として運営するための、
ターゲット・マイルストーン・KPI・役割分担の定義。

数字の根拠は [affiliate-plan.md](affiliate-plan.md)、市況は [affiliate-research.md](affiliate-research.md)。
接続手順は [setup-checklist.md](setup-checklist.md)。

## 0. 収益モデル（ここが全ての前提）

各社の条件を一次情報で確認した結果、**収益源は明確に2階建て**になる。

| 収益源 | 報酬 | 報酬上限 | Cookie | 役割 |
|---|---|---|---|---|
| **マウスコンピューター**（バリューコマース） | 3%（税抜）平均単価15万円 → **約4,500円/件** | **記載なし** | **60日** | **収益の主力** |
| パソコン工房（A8.net） | 2% → 約2,500〜4,000円/件 | — | — | 補助 |
| 楽天市場 | 2〜4% | **1商品1,000円 / 1ユーザー月3,000円** | クリック後24時間以内にカート投入 → 89日以内に購入 | 価格データ源＋小口成果 |

### この表から導かれる、事業上いちばん重要な結論

**楽天でPC本体を売っても報酬は1,000円で頭打ちになる。**
20万円のゲーミングPCも、5万円のグラボも、報酬は同じ1,000円。
一方マウスは上限がなく、Cookieも60日ある（高額商材は検討期間が長いので、これは決定的に有利）。

したがって:

1. **PC本体の導線は必ずマウス（バリューコマース）に向ける。** 楽天には向けない
2. **楽天は「価格データの取得元」と「パーツ・周辺機器の小口成果」に用途を限定する**
3. **バリューコマースの審査通過が、収益化のクリティカルパス**。ここが通るまで収益は事実上頭打ち

→ KPIは「セッション数」ではなく **「マウスへのクリック数」** を主指標に置く。
   セッションが2倍になっても、クリックが楽天にばかり流れれば収益は増えない。

## 1. ターゲット顧客

収益に直結する順に定義する。全員に向けて書くと誰にも刺さらないので、
**記事とツールは原則ターゲットAとBのために作る。**

### ターゲットA:「はじめてゲーミングPCを買う人」← 収益の主力

| 項目 | 内容 |
|---|---|
| 像 | 10代後半〜20代前半。予算15〜25万円。PCの知識は浅い |
| 動機 | 「このゲームを friends と快適にやりたい」。製品ではなく**遊びたいゲーム**から入る |
| 悩み | スペック表の意味がわからない。何を買えば失敗しないかわからない |
| 検索する言葉 | 「モンハンワイルズ 推奨スペック」「ゲーミングPC おすすめ 20万」 |
| 買う先 | **BTOメーカー（マウス・パソコン工房）** ← 報酬が最大 |
| 当サイトの接点 | **スペック診断ツール** |

**この層に届くかどうかで事業の成否が決まる。** 単価が最も高く、
かつ「自作できない＝BTOを買う」ため、報酬上限のないマウスに流れる。

### ターゲットB:「買い替えを検討中の既存ゲーマー」← 収益の第二の柱

| 項目 | 内容 |
|---|---|
| 像 | 20〜30代。予算20〜35万円。前のPCを3〜5年使っている |
| 動機 | 新作が重い、フレームレートが出ない |
| 悩み | **「いつ買うのが得か」がわからない**。今が高値なのか安値なのか判断できない |
| 検索する言葉 | 「RTX 5070 価格 推移」「ゲーミングPC 買い時」 |
| 買う先 | BTO本体、またはGPU単体 |
| 当サイトの接点 | **価格追跡ページ・買い時判定** |

購入意欲が既に高い層なので、**セッションあたりの収益がAより高い**。
リピート訪問しやすく、ブックマーク・指名検索を育てる原資になる。

### ターゲットC:「自作PCユーザー」← 集客装置（直接の収益は小さい）

パーツ価格の追跡が刺さる層。楽天の小口成果しか生まないので**収益期待は低い**が、
技術記事プラットフォームやXでの**拡散力と被リンク**を持っている。
ツールを作ったときに広めてくれるのはこの層。集客のための投資と割り切る。

### 対象外とするもの

- **法人・クリエイター向けPC** — 単価は高いが検討プロセスが全く違い、記事を書き分ける余力がない
- **ノートPC全般** — 競合が桁違いに強く、ゲーミングでの優位性も薄い
- **中古・ジャンク** — アフィリエイト案件がない

## 2. マイルストーンと収益目標

### 前提とするファネル

収益は「セッション × クリック率 × 成約率 × 単価 × 承認率」で決まる。
各数値は下記を前提に置く（実測が出たら差し替える）。

| 指標 | 前提値 | 根拠 |
|---|---|---|
| セッション → ASPクリック率 | 8%（ツールページは12%） | ツールは購入検討の最終段にあるため高い |
| クリック → 成果（マウス） | 1.2% | 高額BTO。Cookie 60日で検討期間を吸収できる |
| クリック → 成果（楽天） | 2.5% | 単価が低く即決されやすい |
| 承認率 | 80% | キャンセル・返品・対象外購入の控除 |
| 単価 | マウス4,500円 / 楽天500円 | 楽天は上限1,000円のため実質500円前後 |

### マイルストーン

| # | 期限 | 状態 | 月間セッション | 月間確定報酬 |
|---|---|---|---|---|
| **M1** | 2026年10月末 | 公開・実データ稼働・記事10本・A8提携 | 300 | **0〜1,000円** |
| **M2** | 2026年12月末 | **バリューコマース審査通過**・記事20本・ツール2本 | 1,500 | **3,000〜8,000円** |
| **M3** | 2027年3月末 | 記事35本・価格180日分・指名検索が発生 | 5,000 | **15,000〜30,000円** |
| **M4** | 2027年9月末 | 記事55本・ツール4本 | 15,000 | **40,000〜70,000円** |
| **M5** | 2028年3月末 | 目標到達 | 30,000 | **100,000〜150,000円** |

### 目標額に届く時期についての訂正

前回の計画で「7〜12ヶ月目で3〜15万円」と書いたが、**上振れ側が楽観的すぎた。**
上のファネルで逆算すると、月10万円に必要なのはおよそ次の規模になる。

```
月10万円 ≒ マウス18件（81,000円）＋ 楽天40件（20,000円）
        ← マウスへのクリック 1,900回／月
        ← 総クリック 約2,900回／月
        ← 月間セッション 約30,000
```

月間3万セッションは、個人サイトが1年で到達できる水準ではない。
**目標の月10〜20万円は、18〜24ヶ月かかる前提で組むのが正しい。**
12ヶ月時点の現実的な着地は月4〜7万円。ここを見誤ると、
順調に伸びている時期に「失敗した」と判断して畳んでしまう。

## 3. KPI

### 主指標（これだけは毎週見る）

| KPI | なぜこれか | M2目標 | M3目標 | M4目標 |
|---|---|---|---|---|
| **マウスへのクリック数／月** | 収益にほぼ比例する唯一の先行指標 | 60 | 300 | 900 |
| **公開記事数（累計）** | 唯一こちらが完全に制御できる変数 | 20 | 35 | 55 |
| **月間セッション** | 上2つの結果として動く | 1,500 | 5,000 | 15,000 |

**セッション数を主指標にしない。** セッションが増えても、クリックが楽天（上限1,000円）
にばかり流れれば収益は伸びない。追うべきは「上限のない案件へのクリック」。

### 補助指標（月次で見る）

| KPI | 意味 | 警戒ライン |
|---|---|---|
| ASPクリック率 | 記事から広告へ送れているか | 5%未満なら導線の設計を見直す |
| マウス比率（マウスクリック ÷ 総クリック） | 高単価側に送れているか | **50%未満なら記事構成の問題** |
| 承認率 | 成果が確定しているか | 60%未満なら訴求と実態のズレを疑う |
| 検索順位10位以内のKW数 | SEOの手応え | M3で10語 |
| 価格記録の連続日数 | データ資産の厚み | 欠損3日以上でActionsを点検 |
| 記事あたりセッション | 記事の質 | 月20未満の記事は書き直すか統合 |

### 見なくてよい指標

- **PV数** — セッションと重複し、水増ししやすい
- **SNSフォロワー数** — クリックに繋がらないフォロワーは事業上の意味がない
- **直帰率** — 価格確認だけして満足して帰るのは正常な行動で、悪い指標ではない

### 計測

```bash
npm run kpi     # 自動で取れるKPIを集計（記事数・価格記録日数・公開待ち）
```

セッション数とクリック数は Cloudflare Web Analytics（無料・Cookieなし）と
各ASPの管理画面から取得し、`docs/kpi-log.md` に月次で追記する。

## 4. 役割と責任

役割を「事業主」と「実装・分析」に分ける。
**判断と対外的な責任はすべて事業主（あなた）に属する。** ここは代行できないし、するべきでもない。

### 事業主（あなた）— 決める人・責任を負う人

| 領域 | 具体的な責任 |
|---|---|
| **対外契約** | ASP登録、広告主との提携申請、規約の遵守。アカウント名義とその責任 |
| **金銭** | 機材の購入判断、報酬の受取口座、確定申告 |
| **一次情報の生成** | 実機の購入・使用・実測・撮影。**これは代行不可能で、かつ本サイトの核心資産** |
| **最終承認** | 記事の事実確認と公開判断（`factChecked` を true にする行為）、データの `verified` 判定 |
| **方針決定** | ターゲットの変更、撤退・継続の判断 |

**週あたりの想定工数: 5〜10時間**

- 記事の事実確認と公開: 2〜3時間（週2本）
- 実測・撮影: 1〜2時間
- KPI確認と方針判断: 30分
- 予備: 2〜3時間

### 実装・分析（Claude）— 作る人・調べる人

| 領域 | 具体的な責任 |
|---|---|
| **開発** | サイト・ツール・収集バッチの実装と保守 |
| **記事の下書き** | 構成と初稿の作成（**公開はしない。承認は事業主の専権**） |
| **調査** | キーワード調査、競合分析、ASP条件の一次情報確認 |
| **分析** | KPI集計、伸びていない原因の特定、改善案の提示 |
| **品質ゲートの維持** | 未検証データが本番に出ない仕組みの保守 |

### 責任分界点（ここを曖昧にしない）

| 事項 | 誰が | 理由 |
|---|---|---|
| 記事の公開 | **事業主のみ** | 内容の責任は運営者に帰属する。AIの下書きを無確認で公開しないための一線 |
| 数値を「検証済み」にする | **事業主のみ** | 出典を自分の目で確認していない数値を検証済みにすると、本サイトの唯一の強みが消える |
| 実測値の生成 | **事業主のみ** | 測っていない数値は書けない。ここを崩したら他のAI量産サイトと同じになる |
| アカウント登録・提携申請 | **事業主のみ** | 本人確認と規約同意を伴う |
| コードの変更 | Claude（事業主がレビュー） | — |
| KPIの集計と分析 | Claude | — |
| 撤退の判断 | **事業主のみ** | — |

## 5. 運営リズム

### 毎週（合計5〜10時間）

| いつ | 何を | 誰が |
|---|---|---|
| 平日 | 記事の下書き作成、コード改善 | Claude |
| 週末 | **下書きの事実確認 → 公開**（週2本） | 事業主 |
| 週末 | 実機の実測・撮影（対象があるとき） | 事業主 |
| 週末 | `npm run kpi` を実行し、主指標3つを確認 | 事業主 |

### 毎月

| 何を | 誰が |
|---|---|
| ASP管理画面からクリック数・成果・承認率を取得 | 事業主 |
| `docs/kpi-log.md` に追記、前月比を分析 | Claude |
| 伸びていない指標の原因分析と打ち手の提案 | Claude |

### 四半期

マイルストーン（M1〜M5）に対する進捗をレビューし、必要なら目標を改定する。

## 6. 撤退・方針転換の基準

事前に決めておかないと、惰性で続けるか、伸びている最中に諦めるかのどちらかになる。

| 時点 | 継続の条件 | 満たさない場合 |
|---|---|---|
| **M1（2026年10月末）** | 記事10本を公開できている | **工数の見積もりが誤り。** 週2本のペースを見直す |
| **M2（2026年12月末）** | バリューコマースの審査に通っている | **収益化の主経路が塞がっている。** 落選理由を確認して再申請。3回落ちたらA8中心に組み替える |
| **M3（2027年3月末）** | 月間セッション2,000以上 **かつ** 成果1件以上 | **集客が機能していない。** ツール中心に方針転換するか、ジャンルを見直す |
| **M4（2027年9月末）** | 月間報酬2万円以上 | **単位時間あたりの収益が最低賃金を大きく下回る。** 撤退を含めて検討する |

**逆に、下記は撤退理由にしない:**

- 3ヶ月で収益が出ない → **正常**。この事業モデルでは6ヶ月かかる
- 記事の順位が付かない → 半年は付かないのが普通
- Xのフォロワーが増えない → 主指標ではない

## 2. 勝ち筋 — 記事の質ではなく「コードで作る参入障壁」

このジャンルは競合が非常に強い（価格.com、大手メディア）ため、レビュー記事だけでは勝てない。
ただし**競合の大半はプログラムを書けない**。そこを突く。

| # | ツール | なぜ競合が真似できないか |
|---|---|---|
| 1 | **BTO価格の日次自動追跡** — 価格推移グラフと「今が買い時か」判定 | 手作業では維持不能 |
| 2 | **ゲーム別スペック診断ツール** — 遊びたいゲームを選ぶと必要構成と該当機種が出る | 診断結果がそのまま購入導線になる |
| 3 | **パーツ互換性チェック** — 電源容量・ソケット・メモリ規格の自動判定 | データ整備とロジックが必要 |

### この設計がAI検索に強い理由

- **価格は毎日変わる** — AIの学習データは常に古く、代替できない
- **診断ツールは実行しないと結果が出ない** — 要約で答えを奪われない

### 価格データの取得方法

**スクレイピングはしない。** バリューコマースと A8.net が商品検索APIを公式提供しているので、
規約内で自動取得する。

## 3. AI執筆の運用ルール

Google が制裁しているのは「AIで書くこと」ではなく **scaled content abuse** である
（根拠は [affiliate-research.md](affiliate-research.md) 第2節）。以下の線を守れば問題ない。

| やる | やらない |
|---|---|
| AIに下書きさせ、**公開前に必ず自分で読んで事実確認する** | 生成物を無編集で自動投稿する |
| 実機の写真・ベンチマーク実測値を最低1つ入れる | 触っていない製品を「使ってみた」と書く |
| 自動収集した価格データという一次情報を載せる | 他サイトの言い換え記事を出す |
| 週2〜3本ペース | 1日に大量公開する |

独自データを自動生成できる構成なので、**他のAI量産サイトよりはるかに低い労力でこの条件を満たせる**。
ここが本プロジェクトの設計の核心。

## 4. 収益見通し

| 時期 | 月間収益 |
|---|---|
| 1ヶ月目 | 0円 |
| 2〜3ヶ月目 | 0〜5,000円 |
| 4〜6ヶ月目 | 5,000〜30,000円 |
| 7〜12ヶ月目 | 30,000〜150,000円 |

> **この表は後に下方修正されている。**
> 楽天の報酬上限が判明した後にファネルから逆算し直した結果、上振れ側（7〜12ヶ月で15万円）は
> 楽観的すぎることが分かった。月10万円には月間約3万セッションが必要で、個人サイトが1年で
> 到達できる水準ではない。**月10〜20万円は18〜24ヶ月かかる前提で組むのが正しく、
> 12ヶ月時点の現実的な着地は月4〜7万円。** 確定版は [roadmap.md](roadmap.md) 第2節を参照。

**3ヶ月で月10万円は届かない。** 半年ほぼ無報酬で続けられるかが最大の関門であり、
だからジャンル選定の第一基準を「興味を持てるか」に置いている。

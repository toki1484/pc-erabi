# 事実検証 — 復元したドキュメントの一次確認

復元した `affiliate-research.md` / `affiliate-plan.md` の数値は、失われたセッションの
**会話ログの要約が出典**であり、一次確認を経ていなかった。2026年9月12日に検証した結果を記録する。

判定の凡例: ✅ 確認できた / ⚠️ 一部誤り / ❌ 確認できない

## ❌ 1. AI Overviews のCTR低下率 — 数値が誤り

| | 復元ドキュメントの記載 | 検証結果 |
|---|---|---|
| 数値 | 2025年12月 -38% → 2026年6月 **-62.7%** | **-58%**（2025年12月時点のデータ） |
| 出典 | `ahrefs.com/ja/blog/ai-overviews-reduce-clicks-june-2026/` | 該当記事は確認できず |

実際の Ahrefs の調査は次のとおり。

- 対象: Keywords Explorer から30万キーワード（AI Overviews が出る15万＋出ない情報収集型15万）
- AI Overviews が出るキーワードの**1位CTR**: 2023年12月 0.073% → 2025年12月 **0.016%**（**-58%**）
- 2025年4月時点の測定では -34.5% だったので、**悪化し続けている**
- 影響は下位ほど小さい（2位 -50.8%、10位 -19.4%）
- 影響は**情報収集型クエリに集中**している

→ **結論の方向は正しいが、具体的な数値と出典は信用できない。** 「情報収集型の記事量産は勝てない」
   という判断自体は、実データ（-58%、かつ悪化傾向）でむしろ強く裏付けられる。

## ⚠️ 2. Google のAI生成コンテンツ規制 — 内容は正しいが、期間が古く危険性を過小評価している

復元ドキュメントは「2026年3月のコアアップデート」で話が終わっているが、実際には**その後も続いている**。

| 時期 | 内容 |
|---|---|
| 2026年3月10日 | コアアップデート＋スパムアップデート。scaled content abuse を標的。該当サイトは**流入50〜80%減** |
| 2026年5月 | コアアップデート。同じ方向を継続 |
| **2026年8月21日** | **スパムアップデート完了。scaled content abuse に加えて「programmatic content」「thin affiliates」を明示的に標的** |

### この事実が本プロジェクトに直接効いてくる

8月のアップデートが名指しした **programmatic content（プログラムで自動生成した大量ページ）** と
**thin affiliates（中身の薄いアフィリエイトサイト）** は、本プロジェクトの中核である
「価格データの自動収集とページ生成」と**設計次第で見分けがつかなくなる**。

制裁されたパターンの特徴（数週間で数十ページ→数千ページ、同一構造、著者名なし、独自データなし、
人間のレビューなし）のうち、**「同一構造の大量ページ」は自動生成と構造的に相性が良い**。

→ **対策を設計に織り込む必要がある。**
>
> - 自動生成ページを**大量に作らない**（数千の型番ページを機械生成しない）
> - ツールは**ページ数を増やさず、1ページで対話的に結果を出す**形にする
> - 価格データは「独自の一次データ」として**人間が読む記事の中で使う**
> - 著者名を明記し、公開前に必ず人間が読む（既存の `factChecked` ゲートを維持）

一方、**AI下書き＋人間レビューの運用は制裁対象ではない**ことも複数の調査で一貫している。
この点は復元ドキュメントの記載どおりで問題ない。

## ✅ 3. 楽天の報酬上限 — 確認できた。ただし例外がある

| 項目 | 内容 |
|---|---|
| 1商品あたり | **1,000円**（楽天キャッシュ） |
| 同一ユーザーあたり | **月3,000円** |
| **例外** | **料率アップ対象商品は「同一ユーザー月3,000円上限」が適用されない** |
| 対象 | 楽天市場、楽天ブックスなど |
| 対象外 | 楽天トラベルなど楽天市場以外のサービスは上記制限の対象外 |

→ ロードマップの「楽天でPC本体を売っても1,000円で頭打ち」という結論は**正しい**（1商品上限は例外なし）。
   ただし「月3,000円上限」には例外があるため、周辺機器で料率アップ対象を狙う余地は残る。

## ⚠️ 4. パソコン工房の条件 — ASPと料率が不正確

| | 復元ドキュメントの記載 | 検証結果 |
|---|---|---|
| ASP | A8.net | **楽天リンクシェア**が主。A8.net・バリューコマース・アクセストレードでも提携可 |
| 料率 | 一律2% | **パソコン 3%(税込) / パーツ 1%(税込) / Windowsタブレット 3%(税込) / 上海問屋 10%(税込)** |

→ **「パーツは1%」が重要。** パーツ・周辺機器の記事を書いてもパソコン工房経由ではほぼ稼げない。
   周辺機器の小口成果は楽天/Amazon側で取る設計にする必要がある。

### 追記（2026年9月12日・実機確認）

A8.net の管理画面で「パソコン工房」を検索したところ、**該当プログラムは0件**だった。
「A8.net でも提携可」という情報は二次情報であり、**実際には提携できない**。

| メーカー | 提携できるASP | 報酬 |
|---|---|---|
| パソコン工房 | **楽天リンクシェアのみ**（サイト審査あり） | 本体3%(税込) / パーツ1%(税込) |
| **ドスパラ** | **A8.net**（ほか複数） | パソコン **3%(税込)** |
| **FRONTIER** | **A8.net** | 要確認 |
| マウスコンピューター | バリューコマース（独占・サイト審査あり） | 3%（未確認） |

→ **A8.net での短期の提携先はドスパラとFRONTIERに変更する。**
   ドスパラはゲーミングPC分野での知名度が高く、報酬率もマウスと同水準の3%。
   パソコン工房の「パーツ1%」のような不利な条件もないため、当初案より条件が良い。

→ **サイト審査のあるASP（バリューコマース・リンクシェア）は記事を5本ほど公開してから申請する。**
   早すぎる申請で落ちると再申請の手間が発生する。

# Xのアフィリエイト界隈の観察

観察日: 2026年9月13日 / 一次データ: 事業主がXで収集したスクリーンショット / 分析: ワッツ

この環境からXには接続できない（egress proxyで遮断）。以下は**事業主が実際にXで収集した投稿**の分析である。

---

## 最初に: 投稿自身の数字が、手法を否定している

「需要から逆算してGPTで投稿を量産する」手法を説くスレッドの、各投稿の実績。

| 投稿の内容 | インプレッション | いいね | 率 |
|---|---|---|---|
| ①需要を探す | 8.3K | 66 | 0.8% |
| ②悩みを掘る | 7.3K | 1 | 0.01% |
| ③投稿を量産 | 6.8K | 4 | 0.06% |
| ④導線をつなぐ | 5.7K | 3 | 0.05% |
| ⑤数字を食わせる | 5K | 4 | 0.08% |

**5,000人に見られて4人しか反応していない。**
この手法で作られた投稿自身が、手法が機能していないことを示している。
スレッド内で誰もこの数字に触れていない。

## 発信者の収益構造

投稿主のプロフィール導線に「**LINEで副業・アフィリエイトについて個別に相談を受け付けています**」とある。

**商品は「アフィリエイトで稼ぐ方法」であり、アフィリエイトそのものではない。**
ノウハウを説く人が、ノウハウを売って稼いでいる構造には利益相反がある。

このプロジェクトは一度、この会話圏の情報を信じて
データを壊している（[fact-check.md](fact-check.md) の Apex Legends の件）。

---

## それでも学ぶべき点が2つある

### 1. 「商品→人」ではなく「人→悩み→商品」の順序

**これは正しく、かつ当社ができていない。**

当社のジャンル選定はこの順だった。

```
事業主の関心（ゲーム・ガジェット） → ゲーミングPC → 案件を探す
```

**需要の側を体系的に検証していない。**
「ゲーミングPCを買う人が、お金を払ってでも解決したい悩みは何か」を一度も調べていない。

ただし部分的には正解を引いている可能性がある。診断ツールは
「どのGPUを買えばいいか分からない」という実在する悩みへの答えになっている。
**偶然かもしれない。検証されていない。**

### 2. 導線がつながっているか

当社の現状。

```
どこか → サイト → ツールを使う → ??? → 終わり
```

**何もつながっていない。** 記事を読んだ人が次にどこへ行くかが設計されていない。
Xアカウントも投稿していない。

これは事実として穴である。ただし**現時点の最大の問題は導線ではなく「誰も来ていない」こと**であり、
優先順位は集客が先。

---

## 採用しないもの

> 「今日の投稿を10本作って。集客3本、教育3本、**体験談2本**、導線2本」

**採用しない。** 理由は2つ。

1. 2026年のGoogleアップデートが潰した scaled content abuse の、X版でしかない。
   そして上の数字が、伸びていないことを示している
2. **「体験談」をGPTに作らせることは、していない体験を書くということ**である。
   `editor` の禁止事項1（触っていない製品を「使った」と書かない）に真正面から違反する

## 結論

**手法の骨格（需要から逆算、導線設計、数字でボトルネックを特定）は正しい。**
**実行部分（GPTで量産、していない体験を書く）は採用しない。**

そして、**この界隈を情報源として常用しない。** 発信者の収益構造が「稼ぎ方を売ること」であり、
過去に一度、ここの情報でデータを壊している。

一次データとして事業主がXで収集したものは価値がある。
**ただし「何を言っているか」ではなく「その投稿がどれだけ伸びているか」を見ること。**

# 追記: 「Claudeで自販機を作ったら月0円→月60万」の検証

観察日: 2026年9月13日 / 一次データ: 事業主がXで収集した投稿全文 / 分析: ワッツ

投稿主は前回と別アカウント（@buttanoteragoya、2026年9月7日投稿）だが、
**収益構造は同じ**である。記事末で「完全ロードマップPDF」を無料配布し、
LINE登録へ誘導し、週1〜2回配信する。**記事そのものが、記事の説明する「自販機」である。**

主張の骨子は次のとおり。

- 教え子「Cさん」（20代会社員・副業経験ゼロ・本人希望で匿名）
- 2月開始、8月に月60万円到達
- 扱う案件は**1つだけ**。「報酬単価2万円台の無料相談型」
- 作業は**週1時間**（月曜朝20分の承認＋平日夜10分の確認）

## 1. 外部データを使わずに崩れる — 月次推移が単価と整合しない

投稿は「案件は唯一1つ」「単価は2万円台」と明記している。
ならば月次の確定報酬は、その単価の整数倍でなければならない。

| 月 | 主張された報酬 | 単価2.0万なら | 単価2.5万なら | 単価2.9万なら |
|---|---|---|---|---|
| 3月 | 1.2万円 | 0.60件 ✗ | 0.48件 ✗ | 0.41件 ✗ |
| 4月 | 6万円 | 3.00件 ✓ | 2.40件 ✗ | 2.07件 ✗ |
| 5月 | 15万円 | 7.50件 ✗ | 6.00件 ✓ | 5.17件 ✗ |
| 6月 | 28万円 | 14.00件 ✓ | 11.20件 ✗ | 9.66件 ✗ |
| 7月 | 44万円 | 22.00件 ✓ | 17.60件 ✗ | 15.17件 ✗ |
| 8月 | 60万円 | 30.00件 ✓ | 24.00件 ✓ | 20.69件 ✗ |

**3月の1.2万円が、単価2万円台の案件では1件にも満たない。**
「初成約」と書かれているのに、1件分の報酬に届いていない。

按分・一部否認・単価変動といった説明はあり得る。
だが投稿はそれを一切説明していない。**説明のない数字は、根拠ではない。**

## 2. 必要な露出量を逆算すると、話が合わない

すべての転換率を**主張に有利な側**に倒して逆算する。

| 段階 | 置いた仮定 | 必要数 |
|---|---|---|
| 確定報酬60万円 ÷ 単価2.5万 | — | 確定 24件/月 |
| 確定率（無料相談型は重複・非該当で落ちる） | 50% | 発生 48件/月 |
| LINE読者 → 無料相談の予約 | 5% | LINE登録 960人/月 |
| プロフ訪問 → LINE登録 | 20% | プロフ訪問 4,800/月 |
| インプレッション → プロフ訪問 | 1% | **インプ 48万/月** |
| 投稿130本/月（週30本） | — | **1本あたり約3,700インプ** |

**前回観察した、実際に発信しているアカウントの投稿が1本5,000〜8,300インプだった。**

つまりCさんは、フォロワーゼロから半年・週1時間の作業で、
**既に発信しているアカウントと同じ桁のインプレッションを、130本すべてで平均して**
出したことになる。仮定を現実的な側に戻せば、必要な露出は数倍に増える。

そして投稿は、**この露出がどこから来るのかを一度も説明していない。**
説明されているのは「投稿を作る仕組み」と「LINEで売らない設計」だけで、
**見られる仕組みが存在しない。** ここがこの種の話に共通して空いている穴である。

LINE登録は3月時点で21人と書かれている。4か月で月960人規模へ伸ばす
機構が、作業時間を減らしながら働いたことになる。

## 3. 採用しないもの

### 単価で案件を選ぶこと

投稿には **EPCも確定率も一度も出てこない。** 出てくるのは「単価2万円台」だけである。

**これは当社が既に一度犯した誤り**である（ConoHa VPSを「最大53,900円」で推薦し、
実際のEPCが2.52だった件）。`market-analyst.md` に評価順序を明記した理由がこれ。

無料相談型・資料請求型は、重複や条件非該当で**確定率が落ちやすい類型**である。
単価だけを見て選ぶと、実効EPCで負ける。

### 経験ゼロの人物に「体験談スタイルの1人称」を30本書かせること

プロンプトは「一次情報:[自分の体験・数字・失敗を貼る]」と本人の材料を要求しており、
前回の「GPTに体験談を作らせる」よりは健全である。

しかし**副業経験ゼロの人物から、失敗談5本・変化型5本を含む30本**が出てくる前提になっている。
さらに投稿は、体験を足す目的を「**"AIっぽさ"が消える**」と説明している。
**体験が、内容ではなく脱臭剤として扱われている。**

`editor` の禁止事項1に抵触する圧力がここにある。採用しない。

### LINEリスト型モデルそのもの

**当社の商材とは構造が噛み合わない。**

このモデルは、読者が**繰り返し消費する悩み**（副業で稼ぐ方法）を持つ場合に成立する。
リストに残り続ける理由があるからである。

ゲーミングPCは**単発の高額購入**である。買った人のリストは、翌月には価値を失う。

ただし**言い換えれば成立する**: 読者の悩みは「PCを買う」ではなく
「**このゲームを快適に動かす**」であり、新作は出続ける。これは反復する需要である。
診断ツールは既にこの側の悩みに答えている。**2階（自社課金）を考える際の材料として記録する。**

## 4. それでも学ぶべき点

| 学ぶ点 | 当社の現状 |
|---|---|
| **7日間売らない**（信頼→提案の順序） | 前回の「人→悩み→商品」と同じ結論に、別ルートから到達している。**正しい可能性が上がった** |
| **商品を1つに絞る**（迷わせない） | 当社はジャンルすら絞れていない。判断は確認時間の実測待ち |
| **生成と承認を分ける** | **既にやっている**。`editor` が書き、事業主が `factChecked` を立てる。独立に同じ構造へ至った |
| **週次で数字を集計し、伸びた構造を分析する** | **既にやっている**。GitHub Actions の週次実行 |
| **ファネルの各段階を数字で持つ**（インプ→プロフ遷移→登録→7日目残存） | **やっていない。計測がまだ1件も動いていない** |

最後の1行が、この投稿から得られる最も痛い指摘である。
**投稿の数字は信用できないが、「段階ごとに数字を持て」という要求自体は正しい。**
当社はいま、来場者数すら取れていない。

## 結論

**方針は変えない。** この投稿は当社の計画を変更する根拠にならない。

- 主張は、投稿自身の数字が内部矛盾を起こしている
- 必要な露出量の説明が存在しない
- 案件選定の基準が単価のみで、当社が既に否定した誤りと同型

**ただし、計測の不在という指摘は受け入れる。** Cloudflare Web Analytics の稼働を
最優先項目として維持する。

モンスターハンターワイルズを遊ぶために、どのくらいのPCが必要なのか。

公式が挙げている数字を、**Steamの公式APIから取得した値のまま**示します。
当サイトはこの取得を自動化しており、毎週月曜に公式との差分を確認しています。

## 結論

| | GPU | CPU | メモリ |
|---|---|---|---|
| **最低** | GeForce GTX 1660 / Radeon RX 5500 XT | Core i5-10400 / Core i3-12100 / Ryzen 5 3600 | 16GB |
| **推奨** | GeForce RTX 2060 SUPER / Radeon RX 6600 | **最低環境と同じ** | 16GB |

ストレージはSSDで75GB程度の空きが必要です。

## 読み方に注意が要る点が3つあります

### 1. 推奨環境のCPUは、最低環境と同じです

表を見て気づくと思いますが、**公式は最低環境と推奨環境で同じCPUを挙げています。**

つまり**このタイトルでは、CPUは推奨環境を判断する材料になりません。**
差が付いているのはGPUだけです。

これを知らずに「推奨環境だから」とCPUに予算を回すと、**GPUに使える金額が減ります。**
判断の順序を間違えることになります。

### 2. 「SUPER」の有無で別の製品です

最低環境は **GTX 1660**、推奨環境は **RTX 2060 SUPER** です。

- GTX 1660 と GTX 1660 SUPER は別製品
- RTX 2060 と RTX 2060 SUPER も別製品

まとめ記事を経由すると、この一語が落ちていることがあります。
当サイトは以前、これが原因で誤った値を載せていました。
[8タイトルを公式と突き合わせた記事](/articles/suishou-spec-wa-shinjite-iika/)に、その顛末を書いています。

中古で買うときも、BTOの構成を選ぶときも、**型番は最後の一語まで確認してください。**

### 3. 推奨環境は「快適に遊べる」の保証ではありません

推奨環境は、**メーカーが想定したある条件での動作**を示すものです。
その条件（解像度、目標フレームレート、アップスケーリングの使用有無）が
明記されているかどうかは、タイトルによって違います。

高い解像度で遊びたい場合や、高いフレームレートを狙う場合は、
推奨環境より上の構成が必要になります。

## 自分の条件で必要なGPUを知る

「フルHDで60fps」なのか「WQHDで144fps」なのかで、必要なGPUは変わります。

[スペック診断ツール](/)で、遊びたい解像度とフレームレートを選ぶと、
必要なGPUの目安が出ます。

ただし**このツールの結果は推定であり、実測値ではありません。**
何をどう計算しているか、何を計算に入れていないか（DLSS、フレーム生成、
レイトレーシングなど）は、[ツールの中身を公開した記事](/articles/spec-shindan-no-nakami/)に
全部書いてあります。

## このページの数字について

Steamの公式APIから取得し、当サイトのデータと1項目ずつ照合したものです。

ゲームはパッチで動作環境の記載が変わることがあります。
当サイトは**毎週月曜に自動で公式との差分を確認**しており、変更があれば更新します。
手作業では気づけない変化なので、そこは機械に見張らせています。

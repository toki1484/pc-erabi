ゲーミングPCを選ぶとき、多くの人はまず公式の「推奨スペック」を見ます。
当サイトの[スペック診断ツール](/)も、その公式の推奨環境を出発点にしています。

では、その推奨スペックはどこまで信用していいのか。

収録している8タイトルについて、**公式の記載と1項目ずつ照合**しました。
結果として9件の食い違いが見つかり、そのうち何件かは**公式側の書き方そのものに原因がある**ことが分かりました。

## やったこと

Steam公式のストアAPIから、各タイトルの最低環境と推奨環境を取得し、
当サイトが持っていた値と機械的に突き合わせました。

Steamに無い3タイトル（VALORANT・フォートナイト・FF14）は自動取得できないため、今回の対象外です。

この照合は誰でも再現できます。当サイトのリポジトリでコマンドを1つ実行するだけです。
やり方は記事末尾に書きます。

## 分かったこと

### 1. 「SUPER」の有無が、まとめ記事では頻繁に消える

いちばん多かった食い違いがこれです。

| タイトル | 当サイトが持っていた値 | 公式 |
|---|---|---|
| モンスターハンターワイルズ（最低） | GTX 1660 **SUPER** | GTX 1660 |
| モンスターハンターワイルズ（推奨） | RTX 2060 | RTX 2060 **SUPER** |
| サイバーパンク2077（推奨） | RTX 2060 | RTX 2060 **SUPER** |

RTX 2060 と RTX 2060 SUPER は別の製品です。GTX 1660 と GTX 1660 SUPER も別物です。
中古で買うときも、BTOの構成を選ぶときも、この一語で性能が変わります。

**当サイトの照合ロジックは、この接尾辞の有無を不一致として検出するように作ってあります。**
実際、今回の食い違いの半分以上がこれでした。

### 2. 推奨環境のCPUが、最低環境と同じことがある

モンスターハンターワイルズの公式記載は、**最低環境と推奨環境で同じCPU**を挙げています。

```
最低: Core i5-10400 / Core i3-12100 / Ryzen 5 3600
推奨: Core i5-10400 / Core i3-12100 / Ryzen 5 3600
```

つまりこのタイトルでは、**CPUは推奨環境を判断する材料になりません。**
差が付いているのはGPUだけです。

これを知らずに「推奨環境だから」とCPUに予算を割くと、GPUに回すべき金額が減ります。
判断の順序を間違えます。

### 3. 発売から年数が経ったタイトルの記載は、更新されないことがある

Apex Legends の Steam ストアページは、2026年9月現在もこう書かれています。

```
最低: GeForce GTX 950 / 6GB RAM
推奨: GeForce GTX 970 / 8GB RAM
```

GTX 970 は2014年のGPUです。この記載どおりのPCで、いま快適に遊べるかというと、
**競技志向で高いフレームレートを狙う人にとっては、まったく足りません。**

一方で、この数字自体は公式の記載です。嘘ではありません。
「起動して遊べる水準」と「勝ちにいく水準」が違うだけです。

**ここに、当サイトが一度やらかした失敗があります。**
国内のブログが「公式推奨」として書いていた、より高いスペックを信じて、
データをそちらに書き換えてしまいました。結果として**公式より大幅に高い要求を表示する状態**を作りました。
公式APIに直接当たって、初めて気づきました。

推奨スペックを他人のまとめ記事から拾うと、こうなります。当サイトも例外ではありませんでした。

### 4. 「何を前提とした推奨なのか」は、書かれていないことが多い

同じ「推奨環境」でも、タイトルによって想定している条件が違います。
解像度がフルHDなのか、目標が60fpsなのか、アップスケーリングを使う前提なのか。

その前提が明記されているタイトルもあれば、書かれていないタイトルもあります。
前提が書かれていない推奨環境は、**どの状態を保証しているのか分からない数字**です。

## 結論：推奨スペックは「起点」であって「答え」ではない

今回の照合から言えることは3つです。

1. **公式の記載を見る。** まとめ記事の孫引きは、型番の一語が落ちます
2. **タイトルごとに、何が推奨の判断材料なのかを見る。** CPUに差がないタイトルもあります
3. **古いタイトルの記載は、快適さを保証しない。** 起動条件と快適条件は別です

当サイトの診断ツールは、公式の推奨環境を基準に、解像度と目標fpsの倍率を掛けて必要なGPUを出しています。
その計算方法と限界は[別の記事](/articles/spec-shindan-no-nakami/)に全部書いてあります。

## 再現のしかた

この照合は当サイトのリポジトリで実行できます。

```bash
npm run fetch:requirements
```

Steam公式APIから最低／推奨環境を取得し、手元のデータとの差分を表示します。
GitHub の Actions からボタン1つでも実行でき、**毎週月曜に自動で回しています。**

ゲームはパッチで動作環境の記載を変えることがあります。
手作業で気づける変化ではないので、自動で見張る以外に方法がありません。

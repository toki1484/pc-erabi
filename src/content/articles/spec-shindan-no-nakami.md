当サイトの[スペック診断ツール](/)は、遊びたいゲームと目標の解像度・フレームレートを選ぶと
「このGPU以上があれば狙えます」という結果を出します。

この記事では、その結果が**どういう計算で出ているのか**と、**どこまで信用していいのか**を公開します。
結論から言うと、**実測値ではなく推定です。** その前提で使ってください。

## なぜ公開するのか

ゲーミングPCの「おすすめ」を出すサイトは無数にありますが、その根拠が書かれていることは
ほとんどありません。順位の理由が分からないランキングは、読む側からすると
「なぜこれを買えばいいのか」が判断できません。

当サイトは根拠を全部書きます。**間違っていたら指摘できる状態にしておくほうが、
長い目で見て信用されると考えているからです。**

## 計算の3ステップ

### ステップ1：タイトルの推奨GPUを基準にする

まず、そのゲームの**公式の推奨環境**に書かれているGPUを出発点にします。
公式が「RTX 2060 推奨」と書いていれば、そこが基準です。

各タイトルの動作環境には出典リンクを付けています。
運営者が公式ページと突き合わせていない項目には、**要確認バッジ**が出ます。

### ステップ2：相対性能スコアに置き換える

GPUの型番のままでは比較できないので、**RTX 4060 を 100 とした相対スコア**に変換します。

| GPU | スコア |
|---|---|
| GTX 1060 | 38 |
| RTX 3060 | 72 |
| RTX 4060 | 100（基準） |
| RTX 4070 | 158 |
| RTX 5070 Ti | 225 |
| RTX 5090 | 390 |

**このスコアは当サイト独自の目安であり、ベンチマークの実測値ではありません。**
順序関係（どちらが速いか）はおおむね正しいはずですが、
「RTX 4070 は RTX 4060 のちょうど1.58倍」という精度はありません。

実機を入手してベンチマークを取り次第、この表は実測値に置き換えていきます。

### ステップ3：解像度とfpsの倍率をかける

解像度を上げれば描画するピクセルが増え、fpsを上げれば1秒あたりの描画回数が増えます。
その分の負荷を倍率で掛けます。

| 条件 | 倍率 |
|---|---|
| フルHD（1920×1080） | 1.0 |
| WQHD（2560×1440） | 1.55 |
| 4K（3840×2160） | 2.6 |
| 60fps | 1.0 |
| 120fps | 1.7 |
| 144fps | 2.0 |

```
必要スコア ＝ 推奨GPUのスコア × 解像度の倍率 × fpsの倍率
```

この必要スコアを満たす**いちばん安い（＝スコアが低い）GPU**を答えとして出しています。

**この倍率も推定です。** 4KはフルHDの4倍のピクセル数ですが、GPU負荷が4倍になるわけでは
ないので2.6としています。この数字に厳密な根拠はなく、経験則です。

## ツールが正しく扱えること

### フレームレート上限のあるタイトル

ELDEN RING やストリートファイター6 のように、ゲーム側でフレームレートが60fpsに
固定されているタイトルがあります。ここで144fpsを選んでも、**表示は一切変わりません。**

ツールはこれを検出して、「60fpsを前提に計算しました」と警告を出し、
無駄に高いGPUを勧めないようにしています。

### VRAM不足の警告

スコアが足りていても、VRAM（グラフィックメモリ）が少ないと
テクスチャ設定を上げたときに息切れします。解像度に対してVRAMが不足している場合は警告を出します。

### 高fpsではCPUが効いてくること

120fps以上を狙う場合、GPUよりCPUが先に頭打ちになることが多いため、
公式推奨より一段上のCPUを見るよう案内しています。

## ツールが扱えないこと（重要）

正直に書きます。以下は現時点で計算に入っていません。

- **DLSS / FSR などのアップスケーリング** — 使えば実質的な負荷は大きく下がります。
  つまりツールの結果は「使わない場合」に寄った、**やや安全側の見積もり**です
- **フレーム生成** — 同様に未考慮です。特に最近のタイトルは公式の推奨環境自体が
  フレーム生成の使用を前提にしている場合があり、そこは各タイトルの注記に書いています
- **レイトレーシング** — 有効にすると要求は大幅に上がります。未考慮です
- **画質設定** — 「高設定」か「最高設定」かで要求は変わります。公式の推奨環境が
  想定している設定に準じています
- **CPUのボトルネック** — 注意喚起はしますが、具体的な型番の判定まではしていません

## どう使うのが正しいか

**「だいたいこのクラス」を絞り込むための道具として使ってください。**
最終的な購入判断の前には、その機種の実機レビューやベンチマークを確認することを勧めます。

このツールの価値は精度ではなく、**「RTX 4060 と RTX 4070 のどちらを見ればいいのか
見当もつかない」状態から、検討範囲を2〜3機種に絞るまでの時間を短縮すること**にあります。

## これから改善すること

- 実機ベンチマークを取得して、相対スコアを実測値に置き換える
- DLSS / FSR の有無を選べるようにする
- 収録タイトルを増やす（現在8タイトル）
- BTOメーカーの実勢価格を日次で追跡し、条件に合う機種を直接表示する

進捗はこのサイトで随時公開します。

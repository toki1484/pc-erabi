サイバーパンク2077を遊ぶために、どのくらいのPCが必要なのか。

公式が挙げている数字を、**Steamの公式APIから取得した値のまま**示します。
当サイトはこの取得を自動化しており、毎週月曜に公式との差分を確認しています。

## 結論

| | GPU | CPU | メモリ | 前提 |
|---|---|---|---|---|
| **最低** | GeForce GTX 1060 | Core i7-6700 / Ryzen 5 1600 相当 | **12GB** | 1080p / 低設定 |
| **推奨** | GeForce RTX 2060 SUPER | Core i7-12700 / Ryzen 7 7800X3D 相当 | 16GB | 1080p / 高設定 |

この表で目を引く箇所が3つあります。順に見ていきます。

## 1. 推奨環境は「1440p」ではない

いちばん誤解されやすいのがここです。

**最低環境も推奨環境も、前提は1080pです。** 違うのは解像度ではなく、画質設定が「低」か「高」かだけです。

推奨環境と聞くと、1段上の解像度、つまり1440pで遊ぶための構成だと受け取りがちです。
しかしこのタイトルでは違います。**推奨環境を満たしても、それは1080pで画質を上げられるという意味であって、
1440pで遊べるという意味ではありません。**

1440pや4Kを狙うなら、推奨環境は出発点ですらありません。
公式が数字を出していない領域なので、**このサイトも、公式が言っていないことは書きません。**

そしてもうひとつ。**公式はフレームレートを示していません。**
「推奨環境で何フレーム出るのか」は、公式情報からは答えられない問いです。

## 2. 最低と推奨で、CPUの世代が6年離れている

| | Intel | AMD |
|---|---|---|
| 最低 | Core i7-6700（2015年） | Ryzen 5 1600 |
| 推奨 | Core i7-12700（2021年） | Ryzen 7 7800X3D |

**6年分の開きがあります。** AMD側はさらに極端で、初代Ryzenから、発売時点で最新世代のゲーミング向け製品へ飛びます。

これは「CPUはそこそこで良い」タイトルではない、ということです。

比較すると分かりやすいので、別のタイトルを並べます。
[モンスターハンターワイルズでは、公式が最低環境と推奨環境で同じCPUを挙げていました](/articles/mhwilds-hitsuyou-spec/)。
あちらではCPUは選択の判断材料になりませんでした。

**同じ「推奨環境のCPU」という欄でも、タイトルによって意味がまるで違います。**
だから、複数のゲームの推奨スペックを平均して「ゲーミングPCにはこのCPU」と決めるやり方は成立しません。

## 3. メモリの最低が12GBである

見落とされやすい数字です。

**12GBという指定は、8GBでは足りないという意味です。**
そして12GBという構成は、市販のPCでは一般的ではありません。

実際に買うときは16GBになります。
最低環境を満たすつもりで8GBのPCを選ぶと、その1点で条件を外します。

## レイトレーシングは、推奨環境の外にある

公式の推奨環境の記載には、**レイトレーシングを使う場合は要求が大幅に上がる**旨の注記があります。

このタイトルはレイトレーシングの見栄えがよく知られていますが、
**上の表の推奨環境は、それを使わない前提の数字です。**
レイトレーシングを有効にして遊ぶつもりなら、推奨環境のGPUでは前提が変わります。

公式がその場合の具体的な構成を示していないため、**ここでも、当サイトは数字を作りません。**

## まとめ

- 推奨環境は**1080p・高設定**の話。1440pの話ではない
- **CPUの要求が高い**タイトル。最低と推奨で6年分の開きがある
- メモリの最低は**12GB**。実質16GBが必要
- **レイトレーシングは推奨環境の外**

自分のPCや検討中の構成が、どのあたりに位置するかは診断ツールで確認できます。
ツールが何を根拠に計算しているかは、[こちらの記事](/articles/spec-shindan-no-nakami/)に書きました。
